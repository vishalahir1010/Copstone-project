# DesignHub — Interactive UI Assignment

React + Vite project implementing all five assignment areas as working frontend flows:
- Food delivery homepage with search, filters, add meal and tracking.
- Spotify-style music dashboard with playlists, search and player state.
- Movie booking journey with movie/theatre/show/seat selection, validation and confirmation persisted in localStorage.
- Flipkart-style cart with products, quantity controls, price summary and validated checkout.
- Cred-style rewards dashboard with points, redemption and activity persistence.

## Run

npm install
npm run dev

## Notes
This is a frontend-only implementation. Real payment processing, restaurant/movie APIs, authentication and server-side order persistence would require a backend/service integration.
